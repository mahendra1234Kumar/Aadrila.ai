# Components Directory

This directory contains all reusable React components for the AADRILA Technologies website.

## Components List

### Header.jsx
- Navigation bar with logo and menu items
- "Get a Demo" CTA button
- Responsive navigation

### Hero.jsx
- Main hero section with title and description
- Call-to-action buttons
- Hero image display

### Industries.jsx
- Displays three industry cards: Healthcare, Lending, Insurance
- Each card has an icon and description

### Products.jsx
- Three product sections: DocSim, DocPilot, Doxtract
- Features and benefits for each product
- Product images and call-to-action buttons

### Blogs.jsx
- Blog posts section
- Three blog preview cards

### Contact.jsx
- Contact form
- Office locations (U.S. and India)
- Footer with copyright

### VisionMission.jsx
- About Us section
- Vision and Mission cards with icons

### Team.jsx
- Team members display
- Featured team member card

## Usage

All components are imported in the pages:
- `Home.jsx` - Uses: Hero, Industries, Products, Blogs, Contact
- `About.jsx` - Uses: VisionMission, Team, Contact

# Run commond
npm run dev, but before run this commond install All dependancy with the help of npm install.
